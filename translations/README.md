# Русские локализации TE и BPM

Два независимых пакета локализации. Игровые скрипты исходных модов и патча не изменяются.

- **BPM:** 7159 ключей текущего английского оригинала и два исправления интерфейса. Основа — перевод Dictator_life из Workshop 3487720283; 425 адресных исправления. Это продолжение перевода из Workshop, а не GitHub fork неизвестного исходного репозитория.
- **TE:** 37298 ключей оригинала; 16156 строк в проверенных редакторских словарях. Остальные строки имеют разное происхождение, включая локальный машинный черновик. Это предварительная редакция, а не полностью вычитанный перевод.
- 625 налоговых строк интеграции и три строки культурных событий находятся в самом патче совместимости. Самостоятельный TE-пакет содержит только свои 37298 ключей и сохраняет исходные налоговые подсказки TE.

Пользовательские инструкции: [BPM](docs/README-BPM.md), [TE](docs/README-TE.md).

## Репозитории пакетов

- [BPM — русский перевод с исправлениями](https://github.com/Artur-Silverhand/better-politics-mod-russian)
- [TE — русский перевод](https://github.com/Artur-Silverhand/vic3-timeline-extended-russian)

В этих репозиториях находятся устанавливаемые файлы. Память перевода, словари и инструменты сопровождения находятся здесь, в `translations/`. Модели, временные исходники и локальные пути не публикуются.

## Проверки

```powershell
python translations\test_loclib.py
python translations\maintain.py audit
python translations\maintain.py package
```

Последняя команда воспроизводит пакеты из `memory/` без нейросетевой модели. Нужны закреплённые локальные исходники проекта; `paths.local.json` позволяет указать их расположение. Сборщик повторно читает реальные исходники, проверяет их английские значения и версию/сборку игры. Расхождение блокирует упаковку.

Проверяются покрытие, уникальность ключей, UTF-8 BOM, синтаксис кавычек, макросы, вложенные игровые вызовы, цели ссылок Concept, иконки, форматирование, переводы строк и числовые значения. Исключения для латинских названий, словесных числительных и исправлений дефектного оригинала перечислены явно и привязаны к конкретным значениям. Успешная синтетика не подтверждает литературное качество или размещение текста в интерфейсе. Игра не запускалась.

Числовая проверка учитывает знак, десятичную запятую, разделители тысяч и диапазоны. Она не доказывает правильность отрицаний и условий в прозе. Отдельные случаи вроде «relations −10» → «снижение отношений на 10» разрешаются только точным исключением с хешами обеих строк.

Порядок совместного набора: **TE → полный BPM → TE русский → BPM русский → патч совместимости**. Для TE-only нужен только TE и его перевод; патч совместимости в таком наборе отключён.

## Обновление исходников

Для проверки нового Workshop-пакета без изменения закреплённого проекта:

```powershell
python translations\maintain.py audit --te-localization "ПАПКА_TE\localization" --bpm-localization "ПАПКА_BPM\localization"
```

Отчёт `runtime/translations/update-report.json` содержит новые, изменённые и удалённые ключи. Код возврата 2 означает, что прежний перевод нельзя выпускать как проверенный для этих исходников. Смена английского значения при прежнем ключе также считается изменением. Изменение версии/сборки игры отмечается отдельно.

Порядок подготовки обновления:

1. Подготовить и проверить новый кандидат исходных модов по основному процессу проекта. Не обновлять закреплённые клоны посреди сборки.
2. Выполнить аудит перевода. Для каждого нового/изменённого ключа перевести новое английское значение и проверить его контекст.
3. Внести проверенные изменения в словари `data/*_overrides.json` и соответствующие записи `memory/*.json`: русский текст, SHA-256 нового английского значения, происхождение. Удалённые ключи убрать из памяти. Это явный этап редакторской приёмки; автоматическая подмена хешей запрещена. При конфликте словарей необходимо убрать прежнее значение или обновить его, чтобы старый перевод не победил новый.
4. Выполнить `python translations\prepare.py`, затем `python translations\build.py`. Неизменённые строки берутся из сохранённой памяти; изменённые ручные строки блокируются до обновления их привязки. Для новых черновых строк можно отдельно использовать локальную модель; её результат не получает статус ручной вычитки.
5. Исправить все замечания, обновить версии пакетов в `maintain.py`, затем выполнить `python translations\maintain.py seal` и `python translations\maintain.py package`.
6. Проверить новые ZIP и интерфейс через Steam. Уже выпущенный ZIP с тем же номером не перезаписывается другим содержимым.

`seal` не принимает новые английские исходники вместо старой памяти молча: сначала нужно явно рассмотреть отчёт и обновить проверенные записи. `package` независимо проверяет финальные значения и точные записанные YAML-файлы.

## Происхождение

`memory/*` хранит русский текст, отпечаток английского оригинала и происхождение каждой строки. `memory/source-lock.json` фиксирует ревизии модов и игру; личных путей в нём нет. Подробные редакторские отчёты находятся в `docs/`.

Первичный корпус TE предварительно переведён локально моделью Argos English–Russian 1.9 через CTranslate2. Тексты не отправлялись внешнему сервису перевода. Словари ручной вычитки имеют приоритет над черновиком. Модель и CUDA не требуются для установки или воспроизведения уже подготовленного пакета.

Авторство исходных и ранее переведённых текстов сохраняется за авторами TE, BPM, Dictator_life и Paradox. Этот каталог не распространяет лицензию основного проекта на чужие тексты.
