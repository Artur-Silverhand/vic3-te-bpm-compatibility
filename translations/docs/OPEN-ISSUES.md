# Состояние русификаторов, 2026-11-08

Собраны BPM 0.1.1 и TE 0.1.1-preview, установлены отдельными локальными модами.
Оригиналы Workshop и игровые наборы не изменены. Архивы 0.1.0 остаются
предварительными и не используются для установки или публикации.

Закрытые замечания:

1. 625 русских налоговых строк интеграции находятся в compatibility patch
   0.7.1-dev; отдельный TE-пакет содержит ровно 37298 исходных ключей. Пять
   общих налоговых подсказок сохраняют самостоятельные подстановки TE.
2. Проверка чисел учитывает знаки; исправлены спред +0,25, границы отрицательных
   эффектов и неоднозначные записи. Словесные эквиваленты разрешены только
   точными хешированными исключениями.
3. Исправлена повторная обработка уже локализованных названий Concept при
   сборке из памяти. Повторная сборка без модели и машинного кэша даёт те же
   русские значения для BPM, TE и строк патча.
4. Полное покрытие, защищённые подстановки, числа, UTF-8 BOM, кавычки,
   повторное чтение YAML и отсутствие нерассмотренных строк только на латинице
   проходят проверку. У патча 100 тестов PASS, новых дефектов графа нет.

Текущий объём: BPM — 7161 ключ, 425 адресных исправлений поверх перевода
Dictator_life; TE — 37298 ключей, из них 16156 в словарях ручной вычитки.
Остальные значения TE включают локальный машинный черновик.

Остаются полная литературная вычитка TE, адресная вычитка оставшегося BPM,
проверка контекста и интерфейса через Steam, наблюдение в кампании и отдельная
публикация/обновление Workshop. Синтетическая проверка не доказывает правильность
всего текста и не подтверждает игровую производительность.

Порядок полного набора: **TE → BPM → TE русский → BPM русский → патч**.
Для TE-only: **TE → TE русский**, патч совместимости отключён.
