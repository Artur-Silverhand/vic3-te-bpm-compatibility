# Better Politics Mod — русский перевод с исправлениями

Русская локализация полной версии **Better Politics Mod** для Victoria 3. Основой служит перевод **Dictator_life** из [Мастерской Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3487720283). В этой сборке добавлены отсутствовавшие строки и исправлены устаревшие описания, неверные ссылки, форматирование и отдельные смысловые ошибки.

Пакет охватывает 7161 ключ, включая две интерфейсные строки. Внесено **425 адресных улучшений**: среди них законы о профсоюзах, политические понятия, подсказки принятия законов, всеобщая забастовка и события американской политики. Весь текст BPM не проходил сплошную литературную вычитку. Отсутствие пропущенных ключей и успешная проверка структуры не означают, что каждая фраза проверена в игре.

## Установка

1. Установите [полный Better Politics Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=2932134122).
2. Распакуйте папку этого русского пакета в `Paradox Interactive\Victoria 3\mod` внутри системной папки «Документы». Если «Документы» перенесены, используйте их фактическое расположение. Внутри папки пакета должны находиться `.metadata` и `localization`.
3. Добавьте пакет в игровой набор лаунчера и включите русский язык игры.
4. Отключите другую русскую локализацию BPM, включая исходный отдельный пакет Dictator_life: его перевод уже включён в эту сборку.

Для игры с Timeline Extended расположите моды **сверху вниз**:

1. Timeline Extended.
2. Better Politics Mod — полная версия.
3. TE — русский перевод.
4. BPM — русский перевод, этот пакет.
5. Патч совместимости Timeline Extended + BPM, версия 0.7.1-dev или новее с проверкой исходников.

Если используете только BPM, достаточно порядка **BPM → BPM — русский перевод**. Сам перевод не заменяет исходный мод или патч совместимости. Он содержит локализацию; игровые системы и правила задают исходные моды и патч.

## Обновления перевода

Перевод сопровождается памятью, привязанной к исходному тексту: для строки сохраняются ключ, отпечаток английского значения и происхождение русского текста. При обновлении исходников прежний перевод переносится как проверенный только при совпадении английского значения. Совпадения одного имени ключа недостаточно.

Отчёт обновления должен отдельно перечислять **новые, изменённые и удалённые ключи**, а также строки, требующие повторной вычитки. Для изменённых и новых строк проверяются смысл, игровые ссылки, переменные, иконки и переводы строк. После этого собирается новая версия и повторяется структурная проверка. Старый пакет не считается автоматически совместимым с обновившимся BPM.

Если заметили ошибку, полезно приложить снимок окна, проблемную фразу и версии игры, BPM, перевода и патча. Подробный перечень редакторских решений находится в `bpm-review.md` исходного проекта.
