# Timeline Extended + Better Politics Mod — 0.6.0-dev

Разрабатываемый мод совместимости для **Victoria 3 1.15.0** и новой одиночной кампании.
Единый синтетический контроль описан ниже. Загрузка, интерфейс, сохранения и длительная кампания
ещё не прошли игровую приёмку; это не проверенный релиз полной совместимости.

Обязательная база:

- [Timeline Extended 48a28e73](https://github.com/jakeOmega/Vic3TimelineExtended/tree/48a28e73ad06c25d4de02edead2ec976a9e8dd35).
- [Полный BPM d785d399](https://github.com/Better-Politics-Mod/Better-Politics-Mod-Vic-3/tree/d785d399001ceaa87a1153ca7e0fb4ba512d8425), папка better-politics-mod.

Workshop TE 1.3.0 отличается от этой ревизии в 12 проверенных файлах. Проверка
кандидата должна использовать закреплённые локальные копии. BPM Lite, Project Utopia
и другие моды в начальный профиль не входят.

## Что входит

- 70 общих законов с политическими условиями BPM и эффектами TE.
- Сохранение 103 общих идеологий BPM; дополнение 24 идеологий персонажей.
- 1267 позиций в 96 специализированных идеологиях BPM; охвачены 39 новых групп законов.
- 12 партий BPM с First Past the Post, включая реакционеров; обновлены ранжирование,
  очистка и историческая поправка свободных выборов.
- Дополнительные ветви женской генерации TE для всех 21 IG BPM.
- Потолок институтов 9 и INCOHERENCE_FACTOR 1; шесть рецептов TE с ограничениями BPM.
- Три технологии, два принципа блоков, три типа модификаторов, два исторических
  задания и согласованное правило избирательного права.
- Восемь GUI-пересечений: сохранены окна BPM, добавлены Nation и налоговые строки TE.
- Адаптер доли частного строительства для FMC и прямого режима.
- Расширение налогового генератора TE с 8 до 21 IG: поддержка, предложения, обещания,
  ИИ, перенос обязательств, облегчённый режим и обработчик Accept Offer.
- Проверки старых налоговых законов BPM переведены на эквиваленты кодекса TE;
  скриптовые реформы меняют ставки без смены carrier, повторные применения идемпотентны.
- Выбор налогового предложения ИИ заменён линейным алгоритмом: 849 вместо 8442
  полей развёрнутого кода, с сохранением порядка TE.
- Устранены 508 повторных объявлений событий/значений; обработчик успешного этапа
  принятия закона оставлен один, из BPM. Восстановлено отсутствовавшее событие
  иностранного переворота 1.15. Три поздние партии TE подчинены активации IG и запретам BPM.
- Заполнение кабинета ограничено 16 попытками и прекращается при отсутствии вставки;
  временный список очищается, повторы и мёртвые/чужие ссылки удаляются.
- Расчёт согласия проходит министров один раз для каждого закона, без двух
  упорядоченных выборок и повторного подсчёта законов. Формула и веса сохранены.

## Установка и запуск через Steam

Первый порядок: **TE → полный BPM → этот патч**, последним в отдельном playset.
Workshop-дубликаты обоих исходных модов должны быть отключены.
Локальные папки размещаются в Documents/Paradox Interactive/Victoria 3/mod.
Documents может находиться в OneDrive. В каждой папке — собственный .metadata/metadata.json.

В рабочем проекте tools/prepare_local_profile.py копирует полные закреплённые игровые
файлы модов и патч в три новые локальные папки с отдельными именами/ID:

```powershell
python .\tools\prepare_local_profile.py --install
```

Для уже установленного профиля проекта применяется tools/update_installed_patch.py:
он обновляет только наш патч, сохраняет резервную копию и останавливается при
обнаружении посторонних правок. Идентификатор патча остаётся прежним; имя в launcher
становится TBCP 3 - Compatibility 0.6.0-dev. Историческое имя папки tbcp_patch_040dev
сохраняется. Повторная установка исходных модов не требуется.

Исходные установки и playset не редактируются; существующие папки новой установки не
перезаписываются. Автоматические relationships пока не объявлены: порядок задаётся
в launcher вручную. Затем запускай игру обычной кнопкой Steam. Скрипты проекта
игру и Steam не запускают.

Начальный P-BASE: te_tax_code_disabled, demographics_full,
free_market_construction_enabled, space_race_colonies_full. Остальные правила и DLC
нужно записать при проверке. Сценарии — в TESTING.md.

## Открытые работы

Адаптеры прямых обращений BPM к старым налоговым законам и скриптовым реформам
реализованы. Полный/customs режимы ещё требуют проверки в игре; начальный
сопоставимый профиль — P-BASE. Позиции и материальные соответствия требуют балансировки.

Все игровые профили, кабинет/расколы, реальные позиции по законам, баланс материальных
налоговых соответствий, GUI RU/EN, революции, продолжение сохранений, поздние эпохи
и производительность остаются предметом приёмки. Полное исследование систем S1–S3
также не объявляется завершённым.

Оптимизация кабинета сохраняет прежнюю нормализацию по всем действующим законам.
Веса новых групп и влияние нейтральных позиций на поздний баланс требуют отдельного
решения. Измерений времени тика, памяти и размера позднего сейва пока нет.

Обновлять отдельной папкой новой версии с последующим выбором в playset. Для отключения
убрать патч из тестового playset. Исходные моды и сохранения на диске не переписываются.
Перенос одного сейва между разными составами модов пока не поддержан.

## Сборка из рабочего проекта

```powershell
python .\tools\verify_patch.py
python .\tools\package_patch.py
```

Сборщик сверяет commits и использованные исходники. Протокол —
docs/validation/build-manifest.json; решения — docs/decisions/; реестр 266 пересечений —
docs/conflicts/overlap-decisions.json. Офлайн-проверки не заменяют движок.

Единый контроль проверяет контракты, синтетические состояния, ссылки и итоговый граф
вызовов. Упаковщик требует свежий PASS и совпадение хешей. Условные/отложенные связи
исходных систем и динамические параметры остаются в отчёте. Статический PASS не
доказывает отсутствие всех игровых зависаний и не гарантирует скорость кампании.
