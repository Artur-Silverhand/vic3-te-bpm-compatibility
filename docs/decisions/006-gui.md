# ADR-006: политические окна и доступ к TE

Статус: файловые адаптеры реализованы и проверены структурно; отрисовка не проверялась.
По указанию пользователя интерфейс в конце проверяет он сам, запуском через Steam.

В исходниках обнаружены восемь одинаковых имён GUI типов:
character_panel_item, country_panel_information_content, ig_item_loyalists_and_radicals,
institution_icon, politics_panel_institutions_content, politics_panel_legitimacy_item,
politics_panel_ruler_item, selected_or_enacting_law_content.

Канонические версии этих типов берутся из BPM. Из файлов TE они удаляются посредством
замены файлов по тому же пути; остальные типы TE сохраняются. Решение убирает
конкурирующие объявления, не предполагая проверенного порядка глобального реестра GUI.

В country_panel_information_content BPM добавлена исходная навигация Nation из TE.
В selected_or_enacting_law_content BPM перенесены ленивые налоговые строки TE;
пять обычных строк эффектов BPM скрываются для группы taxation, чтобы не показывать
два разных описания одного закона. Обработчики кнопок BPM сохранены.

Полные замены файлов необходимы, поскольку точечное объявление ещё одного одноимённого
типа вернуло бы конкуренцию. Генератор проверяет исходные хеши и ожидаемые маркеры;
изменение структуры источников приводит к остановке сборки.

Проверки подтверждают единственность восьми типов после файловых замен, сохранение
остальных типов и callbacks, наличие навигации и налоговых строк, баланс скобок.
Они не подтверждают расположение, размеры, видимость, datacontext и правильность
вызова GUI-функций движком. Это предмет T16 на русском и английском языках.
