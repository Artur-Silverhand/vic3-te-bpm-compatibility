# ADR-002: композиция 70 законов

Статус: реализовано; подтверждено статическими проверками; игровая проверка передана пользователю.
CON-002, FR-06, FR-09, FR-15.

Полное исходное определение берётся из единственного REPLACE среди TE/BPM; если его нет,
из зафиксированной игры. Поверх тела явно компонуются INJECT TE и BPM. Старое определение
игры не добавляется поверх полного REPLACE BPM, чтобы не возвращать удалённые ограничения.

Правила полей:

- Числовые modifier, institution_modifier и acceptance_modifier суммируются через Decimal.
- unlocking_laws, disallowing_laws, unlocking_technologies, requires_law_or объединяются
  без повторов. Эффекты on_activate/on_enact/on_deactivate выполняются последовательно.
- Условия can_enact, can_impose и is_visible сохраняются как конъюнкция.
- Для interventionism, laissez_faire, militarized_police применяется прогрессивность BPM.
  Для этих законов и agrarianism сохраняется скриптовый AI-вес BPM вместо старого веса игры.
- Конфликтующие country_allow_conversion_*_bool остаются под управлением BPM: это часть
  его политической модели религиозных законов. Прочие неизвестные конфликты останавливают сборку.

Альтернативы: INJECT после исходных модов не гарантирует переживания REPLACE; простое
склеивание modifier может скрыто потерять значения; универсальное слияние условий и
весов опасно. Поэтому итоговые REPLACE формируются по перечисленным правилам с проверкой
хешей. Приёмка поведения всё ещё требует ручного запуска через Steam.

Дополнительные доли частного строительства BPM обработаны адаптером ADR-008.
Его влияние на динамическое распределение ещё требует ручной игровой проверки.
