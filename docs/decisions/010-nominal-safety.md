# ADR-010: однозначные определения и обработчики

В 0.5.0-dev проверяется итоговый VFS игра → TE → BPM → патч, а не только прямые
пересечения TE/BPM. Это обнаружило конфликты исходных модов с игрой 1.15.

508 обычных повторных определений событий и script_values получили явного владельца:
модовая версия сохраняется, конкурирующая более низкая версия вырезается по её исходному
пути. Остальные определения файла остаются неизменными. Порядок владельцев: патч,
BPM, TE, игра. Дубль внутри одного владельца останавливает сборку для отдельного решения.
Никакая неизвестная категория не объединяется этим правилом. Все решения и пути —
docs/conflicts/shadow-definitions.json; хеши исходников обязательны.

On_law_checkpoint_success имел effect и в игре, и в BPM, что противоречит установленной
документации on-actions. Оставлен полный обработчик BPM, содержащий голосование, вето
и путь ИИ. Стандартный безусловный переход этапа убран из исходного игрового файла.
Остальные game hooks этого файла сохранены. Дополнительного вызова BPM не добавлено.

BPM тем же путём заменял events/iberia_events/ip4_coup_events.txt, пропуская новое
ip4_coup.11, которое ещё вызывает дипломатическое действие 1.15. Восстановлено только
это событие из закреплённой игры; внутренние .1–.4 остаются у BPM. Ссылка американского
задания BPM приведена к точному объявленному bpm_acw_events.1.

Поздние green/populist/technocratic партии TE получили условие активации IG BPM и
общую проверку его запретов/единственной партии. Семейства запретов заданы явно:
green → radical, populist → reactionary, technocratic → liberal. Веса, технологии и
исходные условия TE сохранены. Это проектная политическая классификация, которую
можно уточнить балансировкой; отсутствие любой проверки запрета было бы обходом BPM.

Проверки подтверждают сохранение оставшихся определений, уникальность выбранных ID,
единственный effect, существование буквальных целей событий и отсутствие новых
циклических связей в консервативном графе. Они не доказывают завершение всех
условных игровых цепочек при произвольном состоянии.
