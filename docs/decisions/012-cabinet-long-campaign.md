# ADR-012 — ограниченный подбор кабинета и линейный расчёт согласия

Статус: реализовано для 0.6.0-dev; синтетические результаты — в
docs/validation/006-cabinet-optimization.md. Игровая приёмка ожидается.

## Основание

Исходники: BPM d785d399, TE 48a28e73, Victoria 3 1.15.0.
Исследование: docs/research/007-long-timeline-assessment.md.
В BPM_CAB_effects.txt цикл заполнения не ограничивает попытки и не проверяет
прогресс; fix дополняет временный список без предварительной очистки.
В BPM_CAB_SYNERGY_effects.txt для каждого закона выполняются две упорядоченные
выборки министров, затем знаменатель ещё раз обходит действующие законы.

## Решение

1. При восстановлении списка очищать временный буфер до и после работы. Сохранять
   уникальные ссылки на живых персонажей своей страны. Не удалять персонажей и
   назначения; большой существующий живой список не обрезать.
2. Оставить исходные веса выбора IG и генерацию кандидата. Вставлять только живого
   кандидата своей страны, которого ещё нет в списке. Отмечать фактическую вставку.
3. Сохранить исходные цели 10/16 кандидатов и ограничение игроком. Выходить после
   попытки без вставки; максимум 16 попыток на вызов. При полном списке не делать
   прежний дополнительный подбор. Недобор допустим до следующего штатного вызова.
4. Для каждого закона получать минимум и максимум за один проход по министрам,
   используя прежнее значение позиции. Считать число законов в том же внешнем
   проходе. Сохранить знаменатель по всем законам и деление разницы на четыре.
   Пустой список даёт ноль и не использует сохранённые scopes прошлого расчёта.
5. Не добавлять постоянный кеш или новые периодические события. Локальные переменные
   пересчёта и флаг вставки инициализируются при каждом вызове.

Генератор заменяет только пять эффектов и добавляет два помощника; остальные
определения двух файлов сохраняются. Замена every_law + двух ordered_in_list на
every_law + every_in_list — единственное точное исключение в проверке добавленных
обходов графа. Иные обходы или увеличение вложенности продолжают блокировать сборку.

## Альтернативы и границы

Постоянный кеш отложен до полной схемы инвалидирования при смене закона, идеологии,
кабинета и страны. Сокращение частоты всех обновлений изменило бы реакцию политики.
Обрезание живого списка может повредить назначения. Веса новых законов и исключение
нейтральных групп из знаменателя меняют баланс и требуют отдельного решения.

Синтетический исполнитель проверяет сгенерированные AST; нативный случайный выбор,
генерация персонажей и функция позиции — явные границы модели. Сохранность кода
выбора проверяется отдельно. Тест не доказывает поведение движка, стоимость сортировки,
рост всей истории персонажей, размер сейва или скорость многовековой кампании.
