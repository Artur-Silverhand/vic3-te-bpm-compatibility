# ADR-001: ограниченный эксперимент до полной политической интеграции

Статус: реализован как исследовательский модуль; в игре не проверен.

Требования: FR-04, FR-05 (частично), FR-08, FR-09 (частично).
Пересечения: CON-001, CON-004, CON-007.

Выбранные действия:

1. Глобальные политические defines следуют числовому контракту SPEC-002.
2. Для общих идеологий сохраняется всё определение BPM. Из TE добавляются только
   отсутствующие группы законов у совпадающих character_ideology. Пустые определения
   BPM сохраняются. Это не распределяет позиции по специализированным идеологиям IG.
3. При REPLACE рецепта TE его тело сохраняется целиком и дополняется только известным
   disallowing_amendments BPM. Если добавляемое поле уже существует, сборка останавливается.

Альтернативы: порядок модов оставляет риск потери INJECT; универсальный deep merge
может испортить триггеры, числовые эффекты и повторяемые шаги. Ручная редакция рецептов
затруднит проверку обновлений. Поэтому выбран проверяемый генератор ограниченных полей.

В BPM два одинаковых REPLACE для ideology_conservative_praetorian в одном файле.
Они разрешены сборщиком только потому, что их тела совпадают после удаления комментариев
и пробельных различий. Различающиеся дубли останавливают сборку.

Проверки: сохранение всего исходного тела BPM; неизменность тела рецепта TE; наличие
целевой поправки; уникальность генерируемых ключей; корректность вложенности при
кавычках/комментариях. Реальную фазу REPLACE и получившиеся значения проверит игра.
