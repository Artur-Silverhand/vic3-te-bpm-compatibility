# Порядок игровых проверок

Пользователь уточнил: не запускать игру напрямую; интерфейс он проверяет сам в конце.
Дальнейшие запуски игры и UI-автоматизация агентом прекращены. Запуск для ручной
приёмки — через Steam. Подготовка кода, сборок и статических проверок продолжается.

Ранее выполнялась попытка контрольного запуска B0 с отдельной папкой runtime/B0.
Был наблюдён загрузочный экран; прохождение до меню и новой кампании не подтверждено.
Ни один игровой сценарий или контроль не получает статус пройденного по этой попытке.
После уточнения пользователя проверка процесса с нашим аргументом userdir не нашла
работающего экземпляра. Чужие игровые процессы не завершались.
