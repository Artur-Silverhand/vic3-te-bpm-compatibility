# Офлайн-проверка кандидата 0.4.0-dev

Дата: 7 ноября 2026. Игра 1.15.0; commits — sources.lock.json.

Выполнено без запуска игры или Steam:

- tools/test_patch.py: **22 теста, PASS**. Проверены сохранение старых позиций и
  приоритетов BPM, копирование новых позиций TE, законы, ограничения PM, FPTP,
  генерация персонажей, состав GUI, технологии/принципы, задания, franchise,
  охват 21 IG налоговым жизненным циклом и обработчиком Accept Offer.
- tools/audit_patch.py: **30 common-файлов** разобраны вторым парсером; скобки
  **7 GUI-файлов** сбалансированы. Проверены **3010** ссылок law_type/ideology/
  amendment_type. Неразрешённых ссылок этих типов, отсутствующих целей REPLACE
  и дублирующихся сгенерированных сущностей не обнаружено.
- Для 22 общих on-action сохранены исходные списочные регистрации, проверены
  callback. Это следует установленной _on_actions.md; повторные вызовы не добавлены.
- Все 17 штатных выходов налогового генератора TE совпали с исходным commit до
  изменения IGS. Генерация выполняется в памяти; новые файлы находятся в patch/.
- PowerShell-коллектор журналов разобран системным синтаксическим анализатором.
  Сам сбор игровых журналов на новый прогон ещё не выполнялся.
- Две упаковки ZIP дали одинаковый SHA256. CRC и содержимое всех 43 элементов
  архива сравнены с подготовленными байтами. Данные — package.json.
- В runtime/local-mods подготовлены полные игровые деревья: 3990 файлов TE,
  2013 файлов BPM, 42 файла патча. Исходные runtime-файлы проверены по Git blobs;
  копии сверены с источниками. Изменены только метаданные локальной идентичности.

Машиночитаемые свидетельства: build-manifest.json, offline-audit.json,
independent-parser.json, package.json, prepared-profile.json. Установка в Documents,
если выполнена, получает отдельный installed-profile.json.

Ограничения: второй парсер — авторский Python-инструмент TE, а не движок; он
используется без применения директив. Ссылки проверены в перечисленных пространствах,
а не во всём API. Проверка GUI не подтверждает datacontext, размеры или отрисовку.
Регистрации on-action не доказывают порядок и правильность взаимодействия состояний.
Ни один B0–B4/C1, T01–T18 не получает PASS по этому отчёту.

Незавершённые профили и исследования перечислены в STATUS.md и ADR-008. Отчёт
не является заявлением полной совместимости и не заменяет ручную приёмку через Steam.
