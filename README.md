# Timeline Extended + Better Politics — Compatibility

Экспериментальный патч совместимости для **Victoria 3 1.15.0**.
Текущий кандидат: **0.6.0-dev**. Синтетические проверки пройдены;
загрузка, интерфейс, сохранения и длительная кампания ожидают игровой приёмки.

Патч связывает расширенные законы и системы Timeline Extended с политической
моделью полного Better Politics Mod. Исходные моды устанавливаются отдельно.

## Установка через Steam Workshop

Подпишись на три мода и включи их в одном игровом наборе. Порядок сверху вниз:

1. [Timeline Extended](https://steamcommunity.com/sharedfiles/filedetails/?id=3721261891).
2. [Better Politics Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=2932134122) — полная версия.
3. Timeline Extended + BPM — Compatibility — этот патч, последним.

Начни новую одиночную кампанию. Старые сохранения и мультиплеер пока не проверены.
Патч экспериментальный; игровые проверки ещё идут. Ссылку на страницу самого патча
добавим после подтверждения первой публикации в Workshop.

## Что интегрировано

- 70 общих законов; позиции BPM для 39 новых групп законов TE.
- Партии, First Past the Post, генерация персонажей, производство и институты.
- Налоговые предложения, обещания и реформы для всех 21 групп интересов BPM.
- Восемь пересечений интерфейса; 508 пересечений объявлений событий и значений.
- Ограниченный подбор кабинета, очистка временных списков, расчёт согласия одним
  проходом по министрам на закон с сохранением прежней формулы.

Состояние и ограничения: [STATUS.md](STATUS.md).
Сценарии проверки в игре: [patch/TESTING.md](patch/TESTING.md).

## Разработка и проверки

Спецификация: [SPEC.md](SPEC.md). Решения: [docs/decisions](docs/decisions).
Инструменты и тесты: [tools](tools). Игровые файлы патча: [patch](patch).
Полные исходники модов, игра, логи, сейвы и резервные копии не включены в Git.
Закреплённые исходники и отличие Workshop: [docs/development/sources.md](docs/development/sources.md).
Локальный профиль разработчика: [patch/README.md](patch/README.md).
Сопровождение после обновлений модов/игры: [docs/development/updates.md](docs/development/updates.md).
Версии задаются в project.json; локальные пути можно задать через paths.local.json.

```powershell
python .\tools\verify_patch.py
python .\tools\package_patch.py
```

Генератор требует отдельно полученные исходники по закреплённым commits и локальные
данные игры. Текущий sources.lock.json и исследовательские JSON фиксируют Windows-пути
исходного прогона; на другом компьютере эти пути и соответствующие отчёты нужно
подготовить для своей установки. Это не автономный CI, скачивающий игру.

Последний контроль: **79 тестов, PASS**; граф 40 258 узлов / 160 881 связь.
Сравнение формул — 400 состояний; смена кандидатов — 5000 циклов.
[Подробности](docs/validation/006-cabinet-optimization.md).
Игровая производительность и поздний политический баланс ещё не измерены.
Проверка процесса обновления и изоляции кандидата: [протокол](docs/validation/007-update-workflow.md).
